# Path to the rxstan C++ headers

Path to the rxstan C++ headers

## Usage

``` r
rxsIncludePath()
```

## Value

a single string: the installed \`include\` directory holding the rxstan
C++ headers

## Author

Lukas A. Widmer

## Examples

``` r
# where the rxstan C++ headers a hand-coded .stan program includes live
rxsIncludePath()
#> [1] "/home/runner/work/_temp/Library/nlmixr2bayes/include"
```
