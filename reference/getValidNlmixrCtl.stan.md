# Validate a stanControl for the nlmixr2 dispatch (mandatory: the default errors before \`nlmixr2Est\` dispatch)

Validate a stanControl for the nlmixr2 dispatch (mandatory: the default
errors before \`nlmixr2Est\` dispatch)

## Usage

``` r
# S3 method for class 'stan'
getValidNlmixrCtl(control)
```

## Arguments

- control:

  a length-1 list holding the control (the \`getValidNlmixrControl\`
  convention)

## Value

a valid \`stanControl\`
